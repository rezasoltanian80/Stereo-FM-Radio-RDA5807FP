# Stereo FM Radio Receiver Using RDA5807FP

A compact, low-power stereo FM radio receiver module designed with the **RDA5807FP** DSP-based tuner IC. This project covers the complete schematic and PCB layout for reliable FM broadcast reception.

---

## 📋 Technical Specifications

| Parameter | Specification |
|---|---|
| **Receiver IC** | RDA5807FP |
| **Operating Voltage** | 2.7 – 3.3 V |
| **Current Consumption** | 20 mA (typical) |
| **FM Frequency Range** | 88 – 108 MHz |
| **Audio Output** | Stereo (3.5 mm Jack) |
| **Antenna Support** | Internal & External |
| **Channel Tuning** | Automatic (Push Buttons) |
| **Frequency Stability** | Very High |
| **Component Count** | 21 Components |
| **PCB Dimensions** | 70 × 30 mm |

---

## 🛠️ Key Hardware Features

- **DSP Architecture:** Digital tuning and signal processing with no external calibration needed.
- **User Interface:** Push buttons for volume control (`VOL+` / `VOL-`), channel seeking (`SEEK+` / `SEEK-`), and `POWER`.
- **Crystal Reference:** 32.768 kHz quartz crystal for precise frequency reference and clock stability.
- **Audio Output Stage:** DC-blocking capacitors for clean direct headphone or external amplifier connection.
